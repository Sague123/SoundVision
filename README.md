# SoundVision

Светомузыка для телевизора: слушает звук, который играет на компьютере, и
рисует на весь экран шоу в цветах обложки текущего трека.

**Сейчас готов этап 0 из плана** — каркас, захват звука, «Сейчас играет» и
отладочная панель с самопроверкой. Картинки шоу ещё нет: она начинается с
этапа 2, когда можно проверять её на реальных треках. Прошлая версия лежит в
[`legacy/`](legacy/README.md) и не собирается вместе с новой.

## Запуск

Готовая сборка берётся из релиза **«SoundVision, этап 0»** на GitHub (его
собирает `.github/workflows/build.yml`):

- **Windows** — `SoundVision-*-portable.exe`, запуск двойным щелчком.
- **macOS (Apple Silicon)** — `SoundVision-*-arm64.dmg`. Подписи Apple нет,
  поэтому первый раз: правый щелчок по программе → «Открыть». Права, которые
  попросит система: запись экрана и микрофон (для захвата звука), автоматизация
  Spotify и Музыки (для «Сейчас играет»).

Клавиши: **K** — самопроверка, **D** — скрыть/показать панель, **F2** — на
другой монитор, **F11** или **Esc** — полный экран, **F12** — инструменты разработчика.

## Что проверить на каждом компьютере (критерий этапа 0)

План требует записать результат на обеих системах. Для этого есть
самопроверка:

1. Запустить программу. Включить музыку в **Spotify**, потом в **YouTube Music
   в Chrome**, дать каждой поиграть полминуты.
2. Нажать **K**. Через ~10 секунд внизу панели появятся итоги, а под ними —
   путь к файлу отчёта (`stage0-<система>-<время>.json`; кнопка «Показать файл
   отчёта» открывает папку).
3. Отчёт прислать мне. В нём: видеокарта и WebGPU, частота кадров, какая
   стратегия захвата звука сработала, что отдают Spotify и Chrome (название,
   обложка и её размер, длительность, идёт ли позиция и как часто система её
   обновляет), права macOS, список мониторов.

Если отчёта нет, а программа молчит, значит что-то не запустилось — смотрите
строку «Помощник» и «Источник» на панели.

## Как это устроено

```
src/main/       главный процесс Electron: окно на нужном мониторе, системный
                звук, помощник «Сейчас играет», файлы отчётов
src/preload/    единственный мост к интерфейсу (window.sv)
src/renderer/   интерфейс: звук → воркер → панель, самопроверка
src/shared/     формат данных помощников, оценка самопроверки, разбор строк
helpers/        помощники «Сейчас играет»: windows (C#), macos (Swift), fake
scripts/        сборка помощников, дымовые проверки для CI
tests/          проверки без Electron: npm test
```

**Звук.** Электрон 44 документирует системный loopback (`audio: 'loopback'`)
как поддерживаемый только на Windows. Поэтому стратегии идут по очереди:
`loopback` → виртуальное устройство (BlackHole и подобные; микрофон не берётся).
На Windows работает первая, на Mac самопроверка покажет, сработала ли она, и
если нет — нужно поставить BlackHole.

**«Сейчас играет».** Отдельная программа печатает JSON по строке в секунду
(формат — `src/shared/now-playing.ts`). Windows: System Media Transport
Controls. macOS: MediaRemote, а если система его закрыла (с macOS 15.4 он
отвечает только программам Apple) — AppleScript для Spotify и Музыки; Chrome с
YouTube Music тогда не виден. Обложка приходит только на смене трека.

## Разработка

```bash
npm install
npm run dev            # окно с горячей перезагрузкой
npm run dev:fake       # без настоящего помощника и звука (заглушки)
npm run helpers        # собрать помощника для этой системы (.NET 8 или Swift)
npm test               # проверки без Electron
npm run typecheck
npm run dist:win       # portable exe  (на Windows)
npm run dist:mac       # dmg arm64     (на macOS)
```

Флаги командной строки: `--display=N`, `--windowed`, `--fake-helper`,
`--audio=test` (тестовый сигнал вместо захвата — только для проверки цепочки,
не музыка), `--selfcheck-exit`, `--report=путь`.

## Чем проверено и чем нет

Проверено здесь (Linux, контейнер без звука и видеокарты): разбор и
склейка сообщений помощника, служба перезапуска, выбор монитора, настройки,
оценка самопроверки, наблюдатель за плеерами — `npm test`; запуск настоящего
Electron в виртуальном дисплее с заглушкой помощника и тестовым сигналом,
запись отчёта.

**Не проверено и не могло быть проверено здесь:** захват системного звука на
Windows и macOS, MediaRemote и AppleScript, настоящая видеокарта, 60 кадров на
RTX 3060 и M3 Pro, перенос окна на телевизор. Помощников C# и Swift собирает и
запускает CI на Windows и macOS; результат смотрится в нём, а полные ответы на
вопросы этапа 0 даст отчёт с ваших машин.
